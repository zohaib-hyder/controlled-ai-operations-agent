# Contributing

This is a synthetic local portfolio application. Preserve tenant isolation, deterministic backend authorization, strict contracts, exact approval bindings, immediate write revalidation, idempotency and bounded execution. Do not connect customer systems or introduce agent shell/arbitrary SQL capabilities.

Discuss substantial scope changes before implementation. Use migrations for schema changes, document decisions, run relevant tests serially and report failures honestly. Use mock AI and disposable test databases. Never commit `.env`, credentials, reports containing private paths, customer data, dumps or generated artifacts. Follow the [local guide](docs/portfolio/DEMO_GUIDE.md).

Owner-authored project material is MIT licensed; third-party material retains its own terms. Contributors must have rights to submit their changes and retain required attribution. No public repository or CLA has been established. No contribution workflow grants publishing or deployment permission. Security issues should follow [SECURITY](SECURITY.md).
