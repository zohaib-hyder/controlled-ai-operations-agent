# Correlation tracing

Operational tracing follows actual durable foreign keys: investigation → proposals → exact policy receipts, approval requests, controlled executions and execution jobs; incidents link through source job/approval. UUID lookup also resolves recorded tool, investigation, policy audit, job, execution and incident correlation references. Every lookup includes tenant predicates and operator root ownership. Unknown/foreign IDs produce the same 404. Custom windows must include the root's creation cohort; no unbounded historical graph search is exposed.

The result contains metadata links and a normalized timeline, without raw goals, tool arguments, evidence payloads, approval binding JSON, credentials or session records. Existing operational IDs stay exact; absent approval or execution links are not fabricated. Read-only diagnostics navigation uses the scoped operations service rather than widening the legacy content APIs for auditors or reviewers. Incident links open their authorized incident detail.

Timeline sources include investigation lifecycle/events, validated tool execution, persisted evidence, proposals/policy decisions, approval requests/decisions, controlled execution events, job transitions, incident history and safe security audit metadata. Ordering is timestamp descending, source label ascending, UUID descending; ties are stable and do not assert causal ordering across independent sources. Some old records lack actor/correlation data; null is retained rather than inventing identity. Service labels identify the emitting subsystem, not a cryptographically authenticated historic worker instance.

Traces cap roots at 10, proposals at 100, each related kind at 100 and event display at 50, with a truncation indicator. Activity pagination caps limit 50/offset 10,000; each source bounds its candidate rows before UNION. Session/login audit records are displayed as plain references when no workflow relationship exists. Tool/entity links and incident links resolve only known operational relationships.
