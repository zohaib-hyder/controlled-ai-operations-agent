4. Request independent approval. Show self-approval is absent and backend self-approval is denied.

6. Return to the original executor. Open Execution jobs and submit exact proposal, decision and approval IDs. Observe the durable job and real worker completion; refresh/inspect the selected job.

8. In an auditor context, follow the actual job ID in Diagnostics. Show linked investigation/decision/approval/receipt timeline. Auditor controls remain read-only.
