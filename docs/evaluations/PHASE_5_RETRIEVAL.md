# Phase 5 measured retrieval evaluation

Dataset: [`phase5-cases.json`](phase5-cases.json), **28 deterministic cases**. Expected resource UUIDs are derived from independent fixture keys, not generated by the retriever. It includes 16 tenant-specific policy queries (billing, unpaid, security, review, duplicates, closure, reactivation/version exclusion, consistency), six account scenarios, two cross-tenant denials, two instruction-bearing ticket cases, an unavailable account and an empty policy search. Reactivation queries exercise effective/expired version selection. Separate security tests add future/expired higher versions, policy prose injection, conflicting observations and missing ledger evidence.

Measured output: [`phase5-results.json`](phase5-results.json). The evaluator executes the real authorized ToolExecutor against disposable PostgreSQL fixtures. It also retrieves account+ledger sources for one explicit payment-conflict check. It never uses paid services.

| Metric | Actual result | Denominator |
| --- | --- | --- |
| Recall@K | 100% | 24/24 expected references |
| Precision@K | 85.7143% | 24/28 retrieved references |
| Top-ranked relevant policy accuracy | 100% | 17/17 searches, including correct empty result |
| Citation validity | 100% | 28/28 generated factual citations |
| Unsupported factual findings | 0 | 28 generated factual findings |
| Conflict detection recall | 100% | 1/1 authorized payment-conflict fixture |
| Cross-tenant leakage | 0 | Canonical tenant and known foreign resource IDs checked |

K is 3 for keyword policy search and 1 for direct resource lookups. Extra keyword matches explain precision below 100%; recall is macro-equivalent here because positive cases each expect one reference. Empty/denied cases contribute no artificial hits. Policy accuracy uses the first result, not equality of the entire result set. The evaluator checks absent leakage using both tenant metadata and actual foreign source IDs.

Run from `backend/`:

```sh
TEST_DATABASE_URL=postgresql+psycopg://northstar:synthetic-local-only@localhost:55432/northstar_test \
PHASE5_EVALUATION_OUTPUT=../docs/evaluations/phase5-results.json \
.venv/bin/pytest tests/test_retrieval_evaluation.py -q
```

The database must be disposable and end in `_test`; the fixture migrates and clears it. Do not run another backend suite against the same database concurrently. Ordinary pytest does not rewrite reports without `PHASE5_EVALUATION_OUTPUT`.

These are small, deterministic synthetic acceptance measurements, not production benchmark estimates. Conflict recall has only one end-to-end denominator; additional unit cases are not misrepresented as measured retrieval recall. Keyword relevance judgments cover this fixture set, not general language understanding. No model-generated factual claim is accepted. Future work should expand independently authored relevance labels, adverse combinations and realistic distributions before external claims.
